# Refiro — minimal Astro starter

A deliberately simple Persian RTL referral-code site with a homepage search and a Taline page.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL Astro prints (normally http://localhost:4321).

## Current demo data
- Brand: Refiro
- Domain configured for canonical URLs: https://refiro.ir
